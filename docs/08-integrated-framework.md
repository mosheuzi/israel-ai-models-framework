# הצעה למסגרת משולבת

## מדוע נדרש שילוב

אין מסגרת בינלאומית אחת שעונה במקביל על כל השאלות הבאות:

- מהי זירת השימוש?
- איזה ערך מבקשים להבטיח?
- ממה מורכבת שרשרת הערך?
- מהי מידת השליטה בכל שכבה?
- מה היקף התלות בגורמים חיצוניים?
- מה משמעות הכשל?
- איזו רמת שליטה נדרשת?
- איזו התערבות היא מידתית?

לכן מוצע להשתמש בכל מסגרת כרכיב מתודולוגי נפרד.

## שמונת שלבי הניתוח

| שלב | שאלה | מקור השראה | תוצר |
|---|---|---|---|
| 1. סיווג זירה | עבור מי, לאיזו משימה ובאיזה הקשר? | OECD Classification | כרטיס זירת שימוש |
| 2. הגדרת ערך | מה מבקשים להבטיח? | OECD Economic Context | תיאור ערך |
| 3. מיפוי השרשרת | אילו שכבות נדרשות ליצירת הערך? | OECD AI Value Chain | מפת שרשרת |
| 4. הערכת שליטה | מה ניתן להפעיל, לשנות, להעביר ולבקר? | EU Sovereignty Framework | פרופיל שליטה |
| 5. הערכת תלות | במי תלויים והאם קיימות חלופות אמיתיות? | JRC | מפת תלות |
| 6. הערכת קריטיות | מה יקרה במקרה של כשל או ניתוק? | UK וקנדה | רמת קריטיות |
| 7. קביעת הדרישה | איזו שליטה נדרשת בכל שכבה? | שילוב | פרופיל יעד |
| 8. זיהוי פער | מה הפער ואיזו פעולה מידתית? | NIST ומדיניות | חלופות פעולה |

## יחידת הניתוח

אין להתחיל מהמושג הרחב "מודל ישראלי". יחידת הניתוח צריכה להיות זירת שימוש מוגדרת, לדוגמה:

- מענה לתושב באזור האישי.
- כלי הוראה ולמידה במערכת החינוך.
- מערכת רפואית תומכת החלטה.
- סטארטאפ תוכנה.
- רובוט תעשייתי.
- מערכת ביטחונית.
- שימור נכס תרבותי או לשוני.
- שימוש אישי במודל מסחרי.

## שכבות אפשריות בשרשרת

- דאטה וזכויות שימוש.
- הכנת נתונים.
- מחשוב לאימון.
- מודל בסיס.
- התאמה ואימון נוסף.
- הערכה ובדיקות.
- תשתית הרצה.
- תוכנה וכלי פיתוח.
- אינטגרציות.
- ניטור ותפעול.
- מיומנויות וכוח אדם.
- חומרה, חיישנים ורכיבים פיזיים.
- הפצה והטמעה.

לא כל שכבה רלוונטית לכל זירה.

## ממדי שליטה מוצעים לבדיקה

- משפטי ושיפוטי.
- דאטה.
- טכנולוגי.
- תפעולי.
- שרשרת אספקה.
- אבטחה.
- יכולת החלפה וניידות.
- המשכיות והתאוששות.
- ידע וכוח אדם.

## סוגי מידע שיש להפריד

| סוג | דוגמה |
|---|---|
| עובדה | המודל מופעל באמצעות API של ספק זר |
| הערכה | מעבר לחלופה צפוי להימשך חצי שנה |
| החלטת מדיניות | נדרשת יכולת הפעלה עצמאית |

לכל תשובה מהותית רצוי לצרף מקור, תאריך, שם מעריך ורמת ביטחון.

## אין להשתמש בציון יחיד בלבד

ציון כללי עלול להסתיר פער קריטי. יש להציג פרופיל רב-ממדי המשווה בין:

- מצב קיים.
- מצב נדרש.
- גודל הפער.
- איכות הראיות.

## סולם התערבות אפשרי

1. קבלת התלות ללא פעולה.
2. ניטור.
3. דרישות רכש, ניידות וזכויות.
4. גיוון ספקים ומדינות.
5. שותפות והסכמים בינלאומיים.
6. תמרוץ תעשייה ומחקר.
7. תשתית משותפת.
8. פיתוח יכולת לאומית.
9. החזקת יכולת גיבוי אסטרטגית.

## שלב התיקוף המומלץ

לפני קביעת ציונים ומשקולות:

1. לבחור חמש עד שבע זירות שימוש שונות.
2. לבצע הערכה עצמאית בידי מספר מעריכים.
3. להשוות את התוצאות.
4. לזהות שאלות עמומות.
5. לבדוק אם המסגרת מבחינה בין תלות סבירה לתלות קריטית.
6. לתקן את הסולמות וההגדרות.
7. רק לאחר מכן לשקול חישוב ציונים משוקללים.
