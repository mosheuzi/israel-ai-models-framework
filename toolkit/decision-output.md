# תבנית לתוצר החלטה

## החלטה נדרשת

משפט אחד המתאר מה נדרש לאשר, לדחות או להמשיך לבדוק.

## ממצאי ארבע שכבות הליבה

|---|---|---|---|
| 0. סיווג וקריטיות |  |  |  |
| 1. שרשרת ערך ותלויות |  |  |  |
| 2. פרופיל שליטה קיים |  |  |  |

## המלצה

החלופה המומלצת, הפער שהיא סוגרת והסיבה שהיא מידתית.

## חלופות שנבחנו

כל חלופה חייבת לתאר דרך קבלת יכולת, תצורת הרצה ושיטת התאמה. RAG או fine-tuning לא יירשמו כחלופה עצמאית.

| חלופה מלאה | דרך קבלת היכולת | הרצה ומיקום | התאמה | פערים שנסגרים | פערים שנותרו | עלות וזמן | ביטחון |
|---|---|---|---|---|---|---|---|

## תנאים והסתייגויות

- הנחות ומידע חסר.
- סיכוני ביצוע ותלות חדשה.
- בעל אחריות לניטור.
- תנאים לשינוי ההמלצה.
- מועד הערכה מחדש.

## עקיבות

יש לצרף את כרטיס הסיווג, מפת השרשרת, פרופיל השליטה, מזהי הראיות וההנמקה לרמת היעד.
